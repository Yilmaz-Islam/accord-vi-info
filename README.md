# Accord VI — Website

## What this is
A website for Accord VI, a student-focused event now in its 6th year (running for 5 years,
currently on the 6th). Audience is 12+ and mostly students, with ~20% accompanying adults
(teachers, family). The event reaches roughly 25,000–50,000 people per edition on Instagram
(handle has ~2,000 followers). Until now the event has only had an Instagram presence — this
is its first website.

## Event details
- Dates: 18–19 October
- Venue: Beaconhouse Cantt Campus, Multan

## Purpose of the site
- Give the event a legitimate home beyond Instagram (sponsors and attendees can be pointed here)
- Showcase what Accord VI is, past editions, and what to expect
- Support the sponsorship pitch — a clean "Sponsor Us" / partnership section
- Collect interest (attendee sign-ups and/or sponsor enquiries)

## Sections to build
- Hero / landing — event name, tagline, dates (18–19 Oct) + venue (Beaconhouse Cantt Campus, Multan), a clear call to action
- About — what Accord VI is, its 6-year history, who it's for
- Sponsorship — tiers (Bronze/Silver/Gold/Platinum) and a "become a sponsor" contact prompt
- Gallery — placeholder grid for photos from past events
- Contact / enquiry — simple form or email link, plus the Instagram link

## Tech
- Plain HTML, CSS, and a little JavaScript — no frameworks. Keep it beginner-friendly and easy to host.
- Single-page site with smooth-scroll navigation is fine to start.
- Mobile-first: most of the audience will view it on phones.

## Style
- Clean and modern, bold but not cluttered. Youthful feel that suits a mostly-student audience.
- Use placeholder text and images where real content isn't available yet, and clearly mark them.
